Documentation

How to build, display, annotate and export synthetic retinal OCT scenes.

Getting started

OCTForge runs on your own computer and opens in your browser. From the start page choose Open workspace. Everything you create is generated locally.

Documentation, About and Privacy are reached from the start page, or from the Help menu in the workspace. They open in a new tab, so your current scene is never lost.

The five workspaces

The tabs across the top of the workspace follow the order of the work:

  • Generator defines the retina: anatomy, pathology, acquisition, realism and artifacts, plus a library of presets.
  • Visualize chooses how the scan is displayed: grayscale or colored layers, palette and opacity.
  • Annotate adds text boxes, arrows, markers and calipers directly on the image, and reports measurements.
  • Export sets output format and resolution and composes multi-panel figures.
  • Projects saves, loads, renames, duplicates, resets and deletes projects.

The current tab decides which tools appear in the toolbar beneath it and which sections appear in the left panel. The status bar at the bottom shows render time, the active tool and the annotation count.

Generator

The left panel has two sections.

  • Scene holds the parameter groups Anatomy, Pathology, Acquisition, Realism and Artifacts. The Basic / Advanced switch shows the most-used controls or all of them. A preview re-renders automatically as you change values.
  • Presets offers a library of pathology presets (for example cystoid macular edema, drusen, macular hole and subretinal fluid), variant sets that show stages of progression, and a randomizer with a selectable scope and amplitude. A variant can be loaded as the current scene or added to the composed figure.

The toolbar carries the rendering controls:

  • Render final produces the full-quality image together with its ground-truth segmentation.
  • Seed fixes the random elements. The same scene and seed always produce the same image.
  • Randomize draws a new scene within physiological bounds.

Visualize

These settings change how the rendered scan is shown. They do not change the underlying image or require a new render.

  • Mode selects raw grayscale, colored anatomical layers, or a pathology-focused (hybrid) view.
  • Palette preset selects a clinical, educational or color-blind-safe palette, or a custom one.
  • Global opacity and the per-layer settings control the strength and color of each layer. Reset to defaults restores the standard configuration.

The color swatch and the W field in the toolbar set the color and stroke width for new items. Auto-label labels each retinal layer using the segmentation ground truth. Delete removes the selected item.

In the left panel, Annotations lists every item and, for the selected item, shows its properties (text, font size, rotation and color). Annotations are stored as vector data and applied when you export; they never alter the rendered image.

Working with text boxes

  1. Create. Choose Text, then drag on the image to draw a box. Start typing immediately. A click without dragging creates a box of default width.
  2. Finish. Press Esc or click elsewhere. A box left empty is discarded.
  3. Select. Choose Select and click the box. Its handles appear only while it is selected.
  4. Move. Drag from inside the box.
  5. Resize. Drag any square handle on the corners or edges. The box never becomes smaller than its text.
  6. Rotate. Drag the round handle above the box. Hold Shift to snap to 15° steps. For a box at the top edge of the image the handle moves below it so that it stays reachable.
  7. Edit. Double-click the box, or click it with the Text tool, to edit the text in place.
  8. Delete. Click the small × beside the selected box, or press Delete.

Text is wrapped inside the box and exported with the same line breaks you see on screen.

Measurements

With the Caliper tool, drag between two points. The distance is shown on the image in micrometers or millimeters, calculated from the scan width and depth of the current scene.

The Measurements section of the left panel lists the central foveal thickness, mean total retinal thickness, foveal pit depth and width, and the thickness of each layer. It can also draw calibrated scale bars (1 mm lateral, 200 μm axial).

Export

The left panel has two sections. Export figure in the toolbar downloads the result using the current Export settings.

  • Export offers presets (Publication, Lecture Slide, PowerPoint, A4 Print, Web Optimized, High-Res Master, Low Bandwidth) and detailed settings: scope (single B-scan or composed figure), format (PNG, TIFF, JPEG, PDF or SVG vector overlay), resolution in DPI, color mode, and whether to include annotations, caliper measurements, scale bars and an educational notice watermark.
  • Composition arranges several scenes as panels (side by side, strips, stacks, 2 × 2 or an automatic grid) with a figure title, panel subtitles and badges, spacing, a layer legend and scale bars. The Single scan / Composed figure switch in the toolbar changes which one the viewer shows.

Projects

The Projects tab lists saved projects. Use Save in the application bar to save the current work; saved projects can be loaded, renamed, duplicated, reset or deleted. They are stored in the projects/ folder of the machine running OCTForge. Creating or opening a project while the current one has unsaved changes asks whether to save them, discard them or cancel.

Patient data

No real patient data OCTForge never imports or displays real patient imagery. It only generates synthetic scans from parameters. Do not present its output as a real clinical image. It is not a diagnostic device.
